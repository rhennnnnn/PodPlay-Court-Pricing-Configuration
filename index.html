Pricing structure

Set a base court price (up to the base group size) and an extra-player surcharge for larger groups, per time band.

Your pricing model is court pricing, meaning customers pay the full court price regardless of group size. The final court price is divided among the participants invited to pay; any free invites' portion is covered by the reservation holder.

Set a fixed price per player

To charge each player a fixed price no matter the group size:

  1. Set Base group size to 1.
  2. Set Base court price to the desired per-player price (e.g. $10.00).
  3. Set Extra player surcharge to the same price (e.g. $10.00).

Now every player is charged exactly that amount, with member discounts still applied.

Member discounts

Add each membership that should get a discount, then set how the discount differs from the default. Type a name and remove any you don't need.

Each membership's discount is applied to the base court price only — the extra-player surcharge is never discounted.
